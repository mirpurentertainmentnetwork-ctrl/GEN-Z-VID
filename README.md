# GEN Z VID Native Android

Native Kotlin / Jetpack Compose migration of GEN Z VID by PMB SIAM.

The existing website remains separately hosted. Android uses the same Supabase document RPCs and media services. The source baseline is saved Sites version 57, commit `d974d3d3c3defcde89d822d4bda678a19fdda17c` (375 original files).

Development and validation are in progress. This repository is **not production-ready**. Native source, feature coverage, test evidence and reproducible build instructions are being added. A compiled test APK alone does not constitute acceptance.
